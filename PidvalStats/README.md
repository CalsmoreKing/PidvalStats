# Barça Ratings — оцінки фанатів

Сайт для голосування фанатів Барселони за гравців після кожного матчу.
Next.js 14 + Supabase (Postgres, Auth, Storage) + Telegram Login Widget,
розгортання на Vercel (безкоштовний тариф обох сервісів достатній для ~200 користувачів).

## Що вже готово

- **`supabase/schema.sql`** — повна структура БД: гравці, матчі, склади,
  голоси (з `unique(match_id, player_id, voter_id)` — фізично неможливо
  проголосувати двічі), ролі адмінів, RLS-політики, функція `finalize_match()`
  (рахує середні оцінки, MVP, оцінку тренера), в'юшки для вкладки "Сезон".
- **`supabase/seed_players.sql`** — весь ростер, який ти скинув (перша
  команда + Атлетік), готовий до вставки.
- **Дизайн**: чорно-фіолетовий фон, золоті акценти, тьмяний трофей, що
  "дихає" на фоні (`app/globals.css`, `public/trophy-watermark.svg` —
  це заглушка-силует, не логотип жодного бренду; заміниш на своє фото).
- **Каркас сторінок**: "Камп Ноу" (`app/page.tsx`), "Матчі"
  (`app/matches/page.tsx` + деталі матчу), "Сезон" (`app/season/page.tsx`) —
  зараз на мокових даних (`lib/mockData.ts`), щоб бачити вигляд одразу.
- **Telegram-логін**: `app/api/auth/telegram/route.ts` перевіряє підпис
  Telegram, створює/оновлює фаната в `voters`, видає сесійний JWT.
- **Голосування**: `app/api/votes/route.ts` — API для голосу, захищене і
  БД-обмеженням, і RLS-політикою (вікно `voting_open`, 1 голос/людина).
- **Автозакриття голосування через 10 хв**: `pg_cron`-джоба в кінці
  `schema.sql` (+ резервний `/api/admin/tick`, якщо `pg_cron` не увімкнеться).

## Що потрібно доробити (наступні кроки)

Це не завершений продукт, а робочий каркас з правильною архітектурою.
Залишилось:

1. **Адмін-панель** — форма для створення матчу, внесення складу,
   хвилин, голів/асистів/карток, кнопка "Відкрити голосування",
   керування списком адмінів. Зараз є лише схема БД під це.
2. **Форма голосування на сторінці матчу** — слайдери 1–10 для кожного
   гравця зі стартового складу + заміни, з викликом `/api/votes`.
3. **Реальні дані замість `mockData.ts`** — підключити Server Components
   до Supabase (`lib/supabase/server.ts` вже готовий).
4. **Завантаження фото гравців і гербів суперників** — просте поле URL
   в адмінці (фото гравців краще брати з офіційних/ліцензійних джерел —
   я свідомо не тягнув їх сам, щоб не порушувати авторські права клубу).
5. **Календар-вʼю** для вкладки "Матчі" (зараз — хронологічний список
   з датами-роздільниками, як ти й описував; повноцінний календар-сітка —
   опційне покращення).

## Розгортання

### 1. Supabase (безкоштовно)
1. Створи проєкт на [supabase.com](https://supabase.com).
2. SQL Editor → встав і виконай **`supabase/schema.sql`**, потім
   **`supabase/seed_players.sql`**.
3. Database → Extensions → увімкни `pg_cron` (якщо доступно на твоєму
   тарифі; якщо ні — див. резервний варіант нижче).
4. Project Settings → API — скопіюй `URL`, `anon public key`,
   `service_role key`, а в JWT Settings — `JWT Secret`.

### 2. Telegram Bot
1. У Telegram відкрий **@BotFather** → `/newbot` → отримай токен.
2. `/setdomain` — вкажи домен, на якому буде сайт (Vercel дасть його
   після першого деплою, можна оновити потім).
3. Токен піде у `TELEGRAM_BOT_TOKEN`.

### 3. Vercel (безкоштовно)
1. Заведи GitHub-репозиторій із цим кодом, підключи до
   [vercel.com](https://vercel.com).
2. В Environment Variables встав усі значення з `.env.example`.
3. Deploy.

### 4. Перший адмін (ти)
Після першого входу через Telegram на сайті виконай у Supabase SQL Editor:
```sql
insert into admins (voter_id, role)
select id, 'owner' from voters where telegram_username = 'твій_юзернейм';
```
Далі новим адмінам ти зможеш давати доступ через адмін-панель (коли її
доробимо) — або тим самим запитом з `role = 'admin'`.

### 5. Резервний cron (якщо pg_cron недоступний)
Зареєструйся на безкоштовному [cron-job.org](https://cron-job.org),
став завдання раз на хвилину на
`POST https://твій-домен.vercel.app/api/admin/tick?token=CRON_SECRET`
(значення `CRON_SECRET` — те саме, що в env).

## Локальний запуск
```bash
npm install
cp .env.example .env.local   # заповнити значеннями
npm run dev
```
