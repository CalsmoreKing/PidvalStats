# PidvalStats — передача (оновлено після міграції 031)

Next.js 14 + Supabase + Vercel. Міграції: `supabase/migrations/002–031` (виконувати вручну по порядку).

## Що зроблено в цій версії
- Міграція 031: чистка даних, фікс голів Рафіньї, автотури (`matches.round_number`, `competitions.round_label`),
  `custom_icons`, індекси, RPC `live_match_ratings` / `live_staff_rating` / `match_voters_count`,
  view `season_player_matches` і `match_goals_audit`, прибирання токенів входу (cron), `voting_duration()`.
- Голосування: upsert (можна змінити голос), порядок ВРТ→ЗАХ→ПЗХ→НАП, Старт/Заміни/Тренер і суддя окремо, лічильник, таймер Г:ХХ:СС, перевірка, що гравець у складі матчу.
- Адмінка: форма деталей матчу (підписи, 2×2, суперник + герб), вкладка «Іконки», фікс зсуву часу при збереженні деталей.
- Головна у 4 колонки, «Сезон» з фільтрами (турнір, місяць, позиція, старт/заміни), «Контакт» сіткою по 4.

## Пастки (без змін)
`goals` = ВСЬОГО голів, `penalty_goals` — частина з них (тепер CHECK penalty_goals <= goals).
RLS на votes/mvp/coach/referee закритий — читання через service client або RPC. View `season_*` навмисно security definer.
Дати конвертувати в UTC у браузері. `finalize_match` завжди ставить status='finalized'.

## Не зроблено
Таблиці ліг через API, OG-прев'ю/кешування, кастомізація профілю (потрібен дизайн-бриф), модерація нікнеймів.
